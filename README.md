# Identity-Access-Management-On-Premises(ACTIVE DIRECTORY)

  This project shows how to use Active Directory to establish Identity and Access Management (IAM) on-premises. It demonstrates how to secure access to organizational resources in a Windows environment, enforce authentication standards, and manage user accounts, groups, and permissions. The project focuses on best practices for role-based access control, centralized identity management, and upholding security compliance in an enterprise network.
  
* Installaton of active directory on the server
* Promote the AD to a DC (domain controller)
* reate a new domain Domain forest 
* Create OUs (Organisation Units)
* Create Group for three location(Lverpool, Manchester and London)
* Create users
* Change DNS of the users PCs to the IP address of the server 
* Create a new GPO (Group policy object)
* Assign policy.
